## 2. 要改的代码（`tools/run_pcg_chain.py` → `_write_perf_report`）

### 2.1 冷隔离结论由**数据自动判定**，不许写死

```python
# 判定：任一冷样本的 DDC 快照前后不一致 → 冷未隔离
isolated = all(p["filesBefore"] == p["filesAfter"] and p["bytesBefore"] == p["bytesAfter"]
               for p in ddc_proofs if p["mode"] == "cold")
```

- `isolated == False` 时输出（与当前入库版一致的措辞）：
  - "**冷（本次未隔离成功）**：… 实测：3 次冷样本 DDC bytes 持续增长（+23/+25/+24 KB、files 266→271）…"
  - "**结论：冷未隔离成功（证据即下方快照表）…两组差值在噪声内，不可当作冷热对比，只能当作 6 次重复采样。**"
  - 汇总表前加上醒目提示（照当前 L59–L61 的句子）
- `isolated == True` 时输出另一分支："冷隔离已验证（快照前后 files/bytes 均未变），cold/hot 两组可作冷热对比"，并在汇总表保留两行（**两个分支都要有，别只写死失败分支**）

### 2.2 措辞替换

| 旧 | 新 |
|---|---|
| "亚毫秒级"/"亚毫秒，无独立可测耗时" | "无法稳定测出独立耗时" |
| "热：走磁盘 DDC（目录变化可有可无）" | "热：走磁盘 DDC（写入属预期）" |
| 汇总表前无提示 | 按 2.1 判定结果插入提示段 |

### 2.3 新增断言 5（`--perf` 与 `--perf-from` 都生效）

> **断言 5：报告的冷隔离结论必须与快照数据一致** —— 从 `notes.ddcProof` 算出 `isolated`，再检查报告文本：`isolated=False` 时报告必须含"冷未隔离成功"且含"不可当作冷热对比"；`isolated=True` 时必须含"冷隔离已验证"。不一致 → FAIL。
