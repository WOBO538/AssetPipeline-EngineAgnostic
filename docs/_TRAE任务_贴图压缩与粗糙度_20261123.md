**让 UE 侧贴图按类型设对压缩（BaseColor / Normal / 数据贴图三档），并把 roughness 从"母材质常量 0.9"升级成"贴图 × 标量"** —— 树皮/树叶粗糙度不同，出图才不像塑料。

## 2. 要改的三件事

### A. 贴图压缩规范化（UE 侧，必做）

新增 helper（放在 `place_manifest.py`）：

```python
def _set_texture_settings(tex, kind):
    """kind: "basecolor" | "normal" | "data"。设置 compression_settings + srgb，返回读回 dict。"""
```

规则（照这张表实现，不要自创第四档）：

| kind | compression_settings | srgb | 用于 |
|---|---|---|---|
| `basecolor` | `TC_DEFAULT` | **True** | BaseColor（含 alpha cutout，DXT5 保留 alpha；**不要改成 TC_MASKED，会丢 alpha**） |
| `normal` | `TC_NORMALMAP` | **False** | Normal（BC5） |
| `data` | **`TC_MASKED`** | **False** | Roughness / Metallic / AO / ORM（线性单通道数据） |

落点：
- `_import_glb`（L93）导入完成后，遍历 `task.get_editor_property("imported_object_paths")` 里路径含 `/Textures/` 或名字含 `_Normal`/`_BC`/`_BaseColor` 的资产，按名字判定 kind 应用一次；
- `_normalize_materials` 里拿到的 `tex_map["BaseColor"] / ["Normal"]` 也各应用一次（保证幂等）；
- 每次都要 **`save_loaded_asset`**，并把读回值写进证据：`{"name": ..., "compression": "TC_Default/TC_Normalmap/TC_Masked", "srgb": true/false}`。

### B. roughness 走贴图（UE 侧，必做）

1. **母材质改造**（`_ensure_material`）：
   - 保留标量参数 `RoughnessScale`（默认 0.9，改名自现有 `Roughness` 或新增别名都行，但**必须保留 `Roughness` 参数名做兼容**，因为 MIC 已有 override）。
   - 新增 `TextureSampleParameter2D`，参数名 **`Roughness`**（`SAMPLERTYPE_LINEAR_COLOR`），采样 R 通道。
   - 连线：`Roughness贴图.R × RoughnessScale → MP_ROUGHNESS`（用 `Multiply` 节点；没有贴图时退化成 `RoughnessScale` 直连，和现在行为一致）。
   - 母材质分变体名规则**不要改**（`M_EAP_Opaque_v2` / `M_EAP_Opaque_v2_N` / `M_EAP_Foliage_Masked_v2` / `..._N`），否则已有的 4 个 MIC 资产路径全变、读回断言全红。
   
   > 兼容做法：母材质只有一个，`Roughness` 贴图参数可以**不给默认贴图**；没有 override 时 UE 用参数默认值（纯白 → ×0.9 = 0.9，等价现状）。

2. **合成 roughness 贴图**（无源贴图时）：
   - 新增 `_make_roughness_texture(base_tex, target_lum_range=(0.65, 0.95))`：
     - 从 BaseColor 取像素 → 转亮度（`0.2126R + 0.7152G + 0.0722B`）→ 线性映射到 `[0.65, 0.95]` 灰度；
     - **UE Python 里没有 PIL**，用 stdlib `zlib` + `struct` 手写 8-bit 灰度 PNG（1024×1024，单通道），写到 `Saved/EAP/tex/<asset_tag>_<slot>_Roughness.png`，再用 `AssetImportTask` 导入到 `/Game/EAP/Materials/Tex/`；
     - 导入后 `_set_texture_settings(t, "data")`（TC_MASKED + 线性）；
     - **确定性**：同一张 BaseColor 两次生成必须字节一致（不许用随机数）。
   - 目标亮度只允许用常量表（树皮 0.95 / 树叶 0.70 之类），不许用随机/时间。
3. **MIC override**：`_normalize_materials` 里对每个 MIC 追加 `set_material_instance_texture_parameter_value(mi, "Roughness", rough_tex)` + `set_material_instance_scalar_parameter_value(mi, "RoughnessScale", 0.9)`，并 `update_material_instance`。
4. **证据**（`evidence[]` 每槽追加）：
   ```json
   "roughnessTex": "/Game/EAP/Materials/Tex/xxx_Roughness.xxx",
   "roughnessScale": 0.9,
   "roughnessMode": "texture" | "scalar",
   "textureSettings": [{"name": "...", "compression": "TC_Masked", "srgb": false}, ...]
   ```

### C. 断言扩展（`tools/run_pcg_chain.py::_run_real_multi`）

**`--multi` 13 条不许动；`--tree` 16 条不许动**（已降级为历史链路）。`--real-multi` 从 17 → **20** 条（`--with-compile` 从 18 → **21**），新增三条：

| 新断言 | 判据 | 数据来源 |
|---|---|---|
| ① 贴图压缩设置合规 | 证据里每张贴图：`BaseColor→TC_Default+sRGB`、`Normal→TC_Normalmap+线性`、`Roughness→TC_Masked+线性`；且至少覆盖 4 张（2 资产 × 2 槽 的 BaseColor/Normal 主贴图） | `place_manifest` 证据 JSON |
| ② MIC 上 roughness 贴图已生效 | 每个 MIC 读回 `Roughness` 纹理参数**非空**，路径以 `_Roughness` 结尾，且 `RoughnessScale` 读回 = 0.9 | 读回脚本（同现有 verify 进程） |
| ③ 贴图设置是持久化的（新进程读回） | 新进程重新加载材质，`get_editor_property("compression_settings")` 仍是上表的值（不是内存假象） | 同上 |

注意：**判据必须失败在"没做"上**——故意删掉 `_set_texture_settings` 调用时，①③ 必须 FAIL。交之前自己反向验一次（改回不设压缩，跑 `--real-multi`，看到 FAIL 再改回来）。
