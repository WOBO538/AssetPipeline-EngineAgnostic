## 2. 要做的事

### A. UE 侧：ISM 实例启用碰撞（G1）

文件：`ue/Content/Python/place_manifest.py`（`place()` 落位后、`verify()` 读回时各补一处）。

1. 落位后：对 `EAP_Placements` 的 ISM 组件
   - `set_collision_enabled(True)`
   - `set_collision_profile_name("BlockAll")`（若项目没有该 profile 就用 `"BlockAllDynamic"` 并在报告里写明实际值）
   - 检查 StaticMesh 是否有碰撞几何（`get_static_mesh()` 的 body setup 非空）；若为空 → **不要静默跳过**，在证据里写 `collisionGeometryMissing: true` 并让 `--parity-check` 的对应断言 FAIL
2. 读回（verify）证据里补字段：`collision: {"enabled": bool, "profile": str, "instanceCount": int, "meshHasCollision": bool}`
3. 不要动现有 `placed_tree_multi.json` / `placed_tree_multi_verify.json` 既有字段，只加 `collision`

### B. Unity 侧：读回逐实例 transform（G2 的前半）

文件：`unity/Editor/ManifestImporter.cs`（`VerifyPlacementsFromArgs`）。

1. 读回 JSON 增加 `instancesDetail`（1892 条）：
   ```json
   {"assetId":"SM_Tree_conifer_PCG_Multi","index":0,
    "t":[x,y,z],"yawDeg":...,"s":[sx,sy,sz]}
   ```
   （Unity 世界坐标，米/度；索引必须与 manifest `placements.items[i]` 顺序一致）
2. 只写文件，不参与 Unity 侧断言；文件已 gitignore（`*.unity_placements_verify.json`）
3. 注意 1892 条 JSON 体积可控（约 300–500 KB），不要压缩

### C. 新命令 `--parity-check`（G2 + G3，4 条断言 + 1 条前置）

```
python tools/run_pcg_chain.py --parity-check --unity "<Unity.exe>" --unity-project "D:\unity\EAP_Unity_Consumer" --manifest schemas\tree_manifest_multi.json
```

**前置**：校验两份证据都存在且新鲜（`docs/placed_tree_multi_verify.json` 的 UE 侧读回 + `schemas/tree_manifest_multi.unity_placements_verify.json` 的 Unity 读回）；不足则先跑 `--real-multi` / `--unity-placements-check`。

坐标换算：**复用 v1.8 的权威实现**（`UeToUnityPos(t)=(x,z,y)`、`unityYaw = -ueYaw`），不要另写一套。

| # | 断言 | 判据 |
|:--:|---|---|
| 1 | 数量与分项一致 | UE 侧 1324 + 568 == Unity 侧 1324 + 568 == 1892 |
| 2 | **逐实例位移误差**（1892 条全查） | `max|Δpos| < 0.01 m` |
| 3 | **逐实例 yaw 误差**（1892 条全查） | `max|Δyaw| < 0.05°`（用角度差取最短弧） |

**产物**：
