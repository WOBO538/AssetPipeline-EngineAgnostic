## 0. 缺口原文（lead 定的验收要求）

任务单 10 原文：「**LOD0 要跟源 glb 对顶点和 UV，不是只看面数碰巧还是 3370**」。

v1.12 现状断言 2 只检查：`LOD0 triCount == 3370/3505`（硬编码） + `manifest.triCount == 同值` + `sectionCount == 2` + `uvChannelCount >= 1`。

**风险实证**：一个恰好 3,370 面的别的网格，只要两段 UV、两个 section，就能原样通过——顶点数会变，但没人查。

lead 实测源 glb 与 UE LOD0 的顶点差（用于定容差）：

| 物种 | glb 顶点（accessor count） | UE LOD0 顶点 | 差 | 原因 |
|---|---|---|---|---|
| conifer | **2,960** | **2,961** | +1 | 导入时法线/UV 接缝顶点分裂 |
| broadleaf | **4,704** | **4,707** | +3（0.06%） | 同上 |

→ **不能要求严格相等**（会把正确实现判 FAIL），也不能只查面数。用「`UE_verts ∈ [src, ceil(src×1.01)]`」这类**有依据的容差**，并写清容差理由。

## 2. 要做的事

### A. `docs/tree_lods.json` 增加 `source` 块（数据来源：glb 二进制解析，不靠猜）

在 `tools/make_tree_lods.py` 里加 glb 解析（直接读 GLB 头 + JSON chunk + accessors，别用 Blender 的导入结果，避免"自证"）：

```json
"source": {
  "glb": "assets/raw/trees/conifer.glb",
  "primitives": 2,
  "triCount": 3370,
  "vertexCount": 2960,
  "uvChannels": 1,
  "materialNames": ["Bark_NormalTree", "Leaves_Pine"],
  "uvBounds": {"min": [0.0, 0.0], "max": [1.0, 1.0]}   // 若能从 accessor 算出就填，算不出写 null
}
```

要求：`source` 由 glb 数据算出（triCount 用 index accessor count/3，vertexCount 用 POSITION accessor count 求和，materialNames 用 primitives.material 反查），加进 JSON 后**LOD1-3 的既有字段一个不动**。

### B. UE 证据补字段（`docs/tree_lods_ue.json`）

LOD0 已有 `vertexCount / uvChannelCount / materialSlotIndices`，补：
- `materialNamesLod0`（已有就复用）；
- 若 UE Python 能读到 LOD0 的 UV 范围（例如 `StaticMesh.get_static_mesh_lod` / `MeshDescription` API），加 `uvBounds`；**读不到就写 `null` 并说明**，不许编。

### C. 断言 2 扩展（`tools/run_pcg_chain.py` → `_run_lod_check`）

在现有 triCount/section/uvChannel 检查之外，加三条：

1. **顶点数**：`src_v <= ue_v <= ceil(src_v * 1.01)`（容差理由写进注释：导入顶点分裂，实测 +1 / +3）；
2. **材质名**：`ue.materialNamesLod0 == src.materialNames`（顺序与数量都比）；
3. **UV 通道数**：`ue.uvChannelCount == src.uvChannels`（现在是 `>= 1`，改成严格相等）。

若 UE 侧 `uvBounds` 可读：再加 UV 范围逐轴误差 < 0.02 的检查；读不到则**跳过并在输出里打印"UV 值未比对（API 限制）"**。

### D. 反验（必须三条，且各自只挂断言 2）

1. 把 `tree_lods.json` 的 `source.vertexCount` 改成 1,000 → 断言 2 FAIL；
2. 把 UE 证据 LOD0 `vertexCount` 改成 `ceil(src*1.05)` → 断言 2 FAIL；
3. 把 UE 证据 `materialNamesLod0` 改成 `["Bark_NormalTree", "Leaves_PineX"]` → 断言 2 FAIL；
4. 对照组：真实证据 → 断言 2 PASS。
反验只动副本/临时文件，**不许把篡改提交**，跑完按字节还原（lead 会核 SHA）。

## 5. 卡住怎么报

- UE Python 读不到 UV 数值 → `uvBounds` 写 `null` + 报告里明确"UV 值未比对，仅比通道数"，**不许编数据**；
