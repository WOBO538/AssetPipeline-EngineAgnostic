## 0. 一句话目标

给两棵真实树（conifer / broadleaf）各补 **3 级 LOD**，让：

- **UE 侧**：StaticMesh 有 4 级 LOD（LOD0 源 3,370 / 3,505 面 + LOD1/2/3 依次递减），1,892 个 ISM 实例能按屏幕尺寸切 LOD；
- **Unity 侧**：Prefab 带 `LODGroup`，同样 4 级，面数与 UE 侧同级一致（同一份 Blender 产物）；
- 新增 `--lod-check` 命令承载判据，**不并进现有门槛**。

## 1. 红线（先看这段）

1. 五条老门槛 + parity 4 条**一条都不许变**：13 / 20 / 21 / 4 / 4 / 4；`--perf` 与断言 5 不动；
2. **LOD0 的源资产不许改**（`assets/raw/trees/*.glb`、已入库 fbx、v1.6 贴图三档与 roughness SHA 全部不动）；
3. LOD 必须是**真几何**（Blender 减面产物），不许把同一个 LOD0 复制三份冒充 LOD、不许只改 screen size 不换网格；
4. manifest 只允许**新增可选字段**（例如 `lod: {levels: [...], source: "blender-decimate"}`），老文件仍合法；
5. 无头环境测不了"视觉切换"，**不许声称验证了渲染效果**——只能断言数据（LOD 数、面数、screen size、引用文件）。

## 2. 要做的事

### A. Blender 无头生成 LOD 源（确定性）

`tools/make_tree_lods.py`（新增，纯 Blender 脚本 + 外层 Python 调用）：

- 输入：`assets/raw/trees/{conifer,broadleaf}.glb`
- 输出：`assets/raw/trees/lod/{species}_lod1.fbx` / `_lod2.fbx` / `_lod3.fbx`
- 减面比例（**Decimate 修改器，COLLAPSE，ratio 固定**）：LOD1 = 0.5、LOD2 = 0.25、LOD3 = 0.10
- 必须：
  - 保留 UV 与两材质槽（Bark/Leaves）的分配；
  - 导出用与 v1.7 相同的口径（`FBX_SCALE_ALL` 保米制 + 沿 X 预镜像，见 `tools/glb_to_fbx.py`），否则 UE/Unity 里尺寸对不上；
  - 记录每级 `triCount / vertexCount / 文件 SHA256 / 比例` 到 `docs/tree_lods.json`（入库）；
  - 幂等：同一输入跑两次，三个 fbx 的 SHA256 必须一致（Decimate 是确定性的，若不一致要查出原因，不许忽略）。

### B. UE 侧装 LOD

`ue/Content/Python/place_manifest.py` 或新 `ue/Content/Python/apply_tree_lods.py`：

- 对 conifer / broadleaf 的 StaticMesh 依次导入 LOD1/2/3：
  - 首选 `unreal.StaticMeshEditorSubsystem.import_lod(...)`（先探测该 API 是否存在）；
  - 若该 API 不存在/不可用，**允许**改用 `set_editor_property` 写 LOD 构建设置（`lod_settings`/reduction）并 `save_loaded_asset`，但必须在证据里写明用了哪条路径；
- 设置 LOD screen size（建议 LOD0=1.0 / LOD1=0.5 / LOD2=0.25 / LOD3=0.1，可调，写进证据）；
- 读回证据 `docs/tree_lods_ue.json`：
  ```json
  {"species": {"conifer": {"numLods": 4,
      "lods": [{"index":0,"triCount":3370,"screenSize":1.0}, {"index":1,"triCount":...,"screenSize":0.5}, ...]}}}
  ```

### C. Unity 侧 LODGroup

`unity/Editor/ManifestImporter.cs`：

- 导入三级 LOD 模型（`Assets/EAP/Trees/Models/{species}_lod{1,2,3}.fbx`，同样按内容哈希复制）；
- Prefab 上加 `LODGroup`，4 级（LOD0 用现有 prefab 网格），screen height 与 UE 口径一致；
- 读回 JSON 增加 `lod: {"levels": 4, "triCounts": [...], "screenHeights": [...]}`。

### D. 新命令 `--lod-check`（4 条断言，不并入老门槛）

```
python tools/run_pcg_chain.py --lod-check --unity "<Unity.exe>" --unity-project "D:\unity\EAP_Unity_Consumer" --manifest schemas\tree_manifest_multi.json
```

| # | 断言 |
|:--:|---|
| 1 | 两棵树 UE `numLods == 4` 且各级 `triCount` 严格递减（>0） |
| 2 | LOD0 面数 == 现有源数据（conifer 3,370 / broadleaf 3,505），**LOD0 没被动过** |
| 3 | Unity 侧 `lod.levels == 4` 且 `triCounts` 与 UE 同级一致（逐级比对，容差 0） |
| 4 | `docs/tree_lods.json` 的 fbx SHA256 与磁盘文件一致（产物可追溯、没被手改） |

**反验（必须做两条，绕过自愈）**：
1. 删掉 UE 侧一个 LOD（或把 LOD0 的 triCount 篡改成别的值）→ 断言 1 或 2 必须 FAIL；
2. 把 Unity 读回 JSON 的某一级 triCount 改掉 → 断言 3 必须 FAIL。
反验用副本/环境变量，**不许把篡改提交进仓库**。
