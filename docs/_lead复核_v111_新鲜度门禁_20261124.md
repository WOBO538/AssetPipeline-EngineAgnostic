## 4. 时区真实性（TRAE 自验，lead 抽查）

Unity 写 `2026-11-24T15:08:23+08:00`；同刻系统本地 15:08、UTC 07:08 —— 偏移来自本地时间，不是"UTC 配 +08:00 标签"。解析侧 `datetime.fromisoformat` 归一化到 tz-aware 后再比，`Z` / `+08:00` / 裸时间三种写法在负验 D 里都正确折算。

## 5. 使用约束（新增，写进 README 的）

1. 顺序固定：`--real-multi` → `--unity-placements-check` → `--parity-check`（`--real-multi` 会刷新 manifest 的 `generatedAt`）；
2. Unity 证据 JSON 是 `.gitignore` 的：**clone 后必须先跑一次 `--unity-placements-check`**，否则对账按设计 FAIL（"缺内部时间戳"）——本地证据不入库、时间戳不伪造，这是有意的；
3. `EAP_PARITY_IGNORE_FRESHNESS=1` 只用于反验，别在正常流程里用。
